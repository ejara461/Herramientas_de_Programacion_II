Lectura 1 — Por qué aparece PHP

Hasta la Clase 2, todo lo que construyeron corría en el navegador: HTML, CSS y JavaScript se ejecutan en el computador del usuario. PHP es distinto — se ejecuta en el servidor, antes de que la página llegue al navegador. El servidor recibe la petición, ejecuta el código PHP, genera HTML como resultado, y ese HTML es lo único que el navegador ve. Por eso PHP puede leer una base de datos o guardar información: el navegador nunca podría hacer eso por sí solo.

Para Gestión de biblioteca, por ejemplo, cuando alguien abre la página de "libros disponibles", el navegador no sabe qué libros hay — es PHP quien consulta esa información en el servidor y construye el HTML con la lista antes de enviarlo.

PHP no nació como un lenguaje de propósito general. En 1994, el programador danés-canadiense Rasmus Lerdorf escribió un conjunto de scripts en C para llevar el control de las visitas a su propia página web personal; los llamó "Personal Home Page Tools" — de ahí las siglas originales. En 1995 los publicó como código abierto para que otros los usaran, y la comunidad empezó a extenderlos para hacer más de lo que Lerdorf había imaginado al principio.

En 1997 dos programadores israelíes, Andi Gutmans y Zeev Suraski, reescribieron el motor desde cero y dieron origen a PHP 3, ya pensado como lenguaje para construir aplicaciones web completas — ahí las siglas pasaron a significar "PHP: Hypertext Preprocessor" (un acrónimo recursivo, porque la propia P inicial es "PHP"). Versiones posteriores fueron agregando lo que hoy se da por hecho: PHP 5 (2004) mejoró la programación orientada a objetos; PHP 7 (2015) reescribió el motor interno y multiplicó el rendimiento; PHP 8 (2020) agregó un compilador JIT y tipado más estricto. Sitios y sistemas usados por millones de personas — entre ellos Wikipedia y (en sus inicios) Facebook — se construyeron sobre PHP, y sigue siendo uno de los lenguajes de servidor más usados en la web hoy en día.

Lectura 2 — La etiqueta <?php ?> y cómo se mezcla con HTML

Un archivo PHP no es "todo código": es HTML normal, con bloques de código PHP metidos donde se necesitan, delimitados por <?php al abrir y ?> al cerrar. Todo lo que está fuera de esas etiquetas se envía al navegador tal cual, como HTML común. Todo lo que está dentro, el servidor lo ejecuta y no llega al navegador — solo llega el resultado que ese código produzca.

<!DOCTYPE html>
<html>
<body>
  <h1>Gestión de inventarios</h1>
  <?php
    echo "<p>Total de productos: 128</p>";
  ?>
</body>
</html>

El navegador nunca ve la palabra echo ni el signo <?php — solo recibe el <h1> y el <p> ya escritos.

Lectura 3 — echo y los comentarios

echo es la instrucción más usada en PHP: envía texto al HTML de salida. Puede escribir texto plano, HTML completo (etiquetas incluidas) o el valor de una variable. Cada instrucción en PHP termina en punto y coma ; — olvidarlo es el error más común al empezar.

Los comentarios no se ejecutan ni se envían al navegador; sirven para que el propio programador (o un compañero de equipo) entienda el código después. En PHP se escriben con // para una línea, o entre /* y */ para varias líneas.

<?php
  // Este comentario no aparece en el navegador
  echo "Bienvenido al sistema de Gestión Asistencia y Permisos";
?>

Lectura 4 — Variables en PHP

Una variable en PHP siempre empieza con el signo $, seguido del nombre — por ejemplo $producto o $cantidad. A diferencia de otros lenguajes, PHP no exige declarar de qué tipo es la variable antes de usarla: se le asigna un valor con = y PHP decide el tipo según ese valor. Los nombres de variable distinguen mayúsculas de minúsculas: $Total y $total son dos variables distintas — un error frecuente al copiar código de un lado a otro.

<?php
  $producto = "Guantes de seguridad";
  $cantidad = 40;
?>

Lectura 5 — Tipos de datos básicos y concatenación

PHP maneja varios tipos de datos simples: cadenas de texto (string, entre comillas), números enteros (integer), números decimales (float) y valores lógicos verdadero/falso (boolean). Para unir texto con el valor de una variable dentro de un mismo echo, PHP usa el punto . como operador de concatenación — no el signo + como en otros lenguajes.

<?php
  $producto = "Guantes de seguridad";
  $cantidad = 40;
  echo "Producto: " . $producto . " - Cantidad disponible: " . $cantidad;
?>

Lectura 6 — Variables dentro de HTML

Cuando se escribe una variable dentro de una cadena de texto entre comillas dobles ("..."), PHP la reemplaza automáticamente por su valor — no hace falta concatenar con el punto. Esto no ocurre con comillas simples ('...'): ahí el texto se muestra literal, incluyendo el símbolo $. Por eso, al mezclar PHP con HTML, la elección de comillas no es un detalle de estilo — cambia el resultado.

<?php $nombreProyecto = "Gestión comportamental"; ?>
<h2>Bienvenido a <?php echo "$nombreProyecto"; ?></h2>

Lectura 7 — Decisiones con if / else

Hasta ahora el código siempre hace lo mismo, sin importar los valores. Con if se puede decidir qué mostrar según una condición: si la condición entre paréntesis es verdadera, se ejecuta el bloque entre las primeras llaves { }; si es falsa, se ejecuta el bloque de else (opcional). PHP usa == para comparar igualdad (no confundir con =, que asigna un valor) y operadores como >, <, >=, <= para comparar números.

<?php
  $cantidad = 3;
  if ($cantidad > 0) {
    echo "Hay stock disponible";
  } else {
    echo "Sin stock";
  }
?>

Esta clase solo cubre if/else simple, con una condición. La variante con varias condiciones encadenadas (elseif) y la instrucción switch se ven con más profundidad en la Clase 4.
