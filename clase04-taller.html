Práctica de PHP: elseif, switch y operadores de asignación — 60 minutos

Bloqueado: esperando activación del docente.
Datos del estudiante
Variante A — Agenda de contactos

Variables fijas: $nombreContacto, $telefono, $categoria ("familia"/"trabajo"/"amigo"/"otro"), $favorito (booleano), $vecesContactado (entero). Usa datos ficticios.

Mínimo: ejecuta el código 4 veces, una por cada valor de $categoria, y pega el código junto con el resultado de las 4 ejecuciones.

Mínimo: igual que el Ejercicio 1, las 4 ejecuciones.

Mínimo: 4 operaciones compuestas encadenadas en la misma secuencia.

Mínimo: ejecuta con favorito true y false (2 de las 4 ejecuciones ya cubiertas por el Ejercicio 1/2 sirven de base).

Variante B — Lista de tareas

Variables fijas: $descripcionTarea, $estado ("pendiente"/"en progreso"/"completada"), $prioridad ("alta"/"media"/"baja"), $diasRestantes (entero). Usa datos ficticios.

Mínimo: ejecuta el código 3 veces, una por cada valor de $estado, y pega el código junto con el resultado de las 3 ejecuciones.

Mínimo: ejecuta el código 3 veces, una por cada valor de $prioridad.

Mínimo: 4 operaciones compuestas encadenadas en la misma secuencia.

Mínimo: ejecuta el caso urgente y al menos un caso no urgente.

Variante C — Inventario simple

Variables fijas: $nombreProducto, $categoriaProducto ("electrónica"/"aseo"/"papelería"), $stock (entero), $precioUnitario (decimal), $prioritario (booleano, separado de la categoría). Usa datos ficticios.

Mínimo: ejecuta el código 4 veces, una por cada rango de $stock, y pega el código junto con el resultado de las 4 ejecuciones.

Mínimo: ejecuta el código 3 veces, una por cada categoría.

Mínimo: 4 operaciones compuestas encadenadas en la misma secuencia.

Mínimo: ejecuta el caso de alerta y al menos un caso sin alerta.
