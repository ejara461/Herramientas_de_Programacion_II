Funciones vistas hasta esta clase

Estas son las únicas funciones que necesitas para resolver el taller. Si tu código usa algo distinto a esto, revisa si de verdad lo necesitas.

FunciónQué hace
echoImprime texto o el valor de una variable en la página.
. (concatenación)Une texto y valores de variables en una sola cadena, por ejemplo echo "Hola " . $nombre;.
"$variable" (interpolación)Dentro de comillas dobles, PHP reemplaza automáticamente el nombre de una variable por su valor, sin necesidad del punto de concatenación.
== , < , > , <= , >= , != (comparación)Comparan dos valores dentro de una condición. == es "igual a" (no confundir con =, que asigna un valor).
! (negación)Invierte una condición: !$conexion se lee "si $conexion NO es verdadero".
if / elseEjecuta un bloque de código u otro según si una condición es verdadera o falsa.
elseifAgrega condiciones adicionales a un if, evaluadas en orden, cuando hay más de dos caminos posibles.
switchCompara una misma variable contra varios valores posibles (cada uno con case), en vez de encadenar varios if/elseif.
breakDentro de un switch, corta la ejecución para que no siga cayendo a los case siguientes. Si se omite, el código sigue ejecutando el case de abajo aunque no coincida (lo que se conoce como fallthrough).
+= , .= , etc. (asignación compuesta)Forma corta de actualizar una variable usando su propio valor anterior, por ejemplo $contador += 1; en vez de $contador = $contador + 1;.
mysqli_connect()Abre la conexión con el servidor MySQL. Recibe 4 datos en orden: servidor, usuario, contraseña y base de datos. Si funciona, devuelve un objeto de conexión; si falla, devuelve false.
mysqli_connect_error()Devuelve el mensaje de error que dio MySQL cuando mysqli_connect() falló. Solo se usa justo después de un intento de conexión fallido.
die()Detiene la ejecución del script inmediatamente e imprime el mensaje que le pasas. Por eso el if que la usa no necesita else: si el script sigue, es porque no entró ahí.
mysqli_query()Envía una instrucción SQL (SELECT, INSERT, etc.) usando una conexión ya abierta, y devuelve el resultado. No imprime nada por sí sola.
mysqli_error()Devuelve el mensaje de error que dio MySQL cuando mysqli_query() falló (por ejemplo, un error de sintaxis en el SQL).
mysqli_num_rows()Cuenta cuántas filas trajo un resultado de un SELECT.
mysqli_fetch_assoc()Trae una fila del resultado como arreglo asociativo (columna → valor). Cada llamada trae la fila donde va el resultado y avanza a la siguiente.
mysqli_close()Cierra la conexión manualmente. Es opcional: PHP la cierra solo al terminar el script.
