Preguntas — Variante A (Gestión de inventarios)

1. Con este código, ¿qué imprime si $stock = 8?

if ($stock == 0) { echo "Agotado"; }
elseif ($stock < 10) { echo "Bajo"; }
elseif ($stock < 50) { echo "Medio"; }
else { echo "Alto"; }

2. En una cadena de elseif, ¿en qué orden se evalúan las condiciones?

3. ¿Cuándo conviene usar switch en vez de elseif?

4. A este switch le falta el break del primer case. Si $categoriaProducto = "electrónica", ¿cuántos mensajes imprime?

switch ($categoriaProducto) {
    case "electrónica":
        echo "Revisar garantía. ";
    case "aseo":
        echo "Verificar caducidad. ";
        break;
    case "papelería":
        echo "Sin revisión especial. ";
        break;
    default:
        echo "Categoría no reconocida.";
}

5. Si un switch no tiene default y ningún case coincide con el valor, ¿qué ocurre?

6. Si $total = 10; luego $total *= 2; luego $total += 5; ¿cuál es el valor final?

7 (abierta). Explica en tus palabras por qué el break es necesario en un switch, usando el ejemplo de la pregunta 4.

8 (abierta). En Gestión de inventarios se aplica 5% de descuento a los productos de categoría "electrónica" o "aseo", y ningún descuento a "papelería". Escribe el switch que implementa esta regla correctamente (incluyendo los break necesarios) y explica tu solución.

Preguntas — Variante B (Gestión Asistencia y Permisos)

1. Con este código, ¿qué imprime si $estado = "aprobado"?

if ($estado == "pendiente") { echo "En espera"; }
elseif ($estado == "aprobado") { echo "Permiso concedido"; }
elseif ($estado == "rechazado") { echo "Permiso denegado"; }
else { echo "Estado desconocido"; }

2. En una cadena de elseif, ¿en qué orden se evalúan las condiciones?

3. ¿Cuándo conviene usar switch en vez de elseif?

4. A este switch le falta el break del primer case. Si $estado = "pendiente", ¿cuántos mensajes imprime?

switch ($estado) {
    case "pendiente":
        echo "En espera de aprobación. ";
    case "aprobado":
        echo "Permiso concedido. ";
        break;
    case "rechazado":
        echo "Permiso denegado. ";
        break;
    default:
        echo "Estado desconocido.";
}

5. Si un switch no tiene default y ningún case coincide con el valor, ¿qué ocurre?

6. Si $dias = 5; luego $dias -= 2; luego $dias -= 1; ¿cuál es el valor final?

7 (abierta). Explica en tus palabras por qué el break es necesario en un switch, usando el ejemplo de la pregunta 4.

8 (abierta). En Gestión Asistencia y Permisos, los permisos "pendiente" y "en revisión" deben mostrar el mismo mensaje ("Aún sin decisión"), mientras que "aprobado" y "rechazado" tienen mensajes propios. Escribe el switch que implementa esta regla (incluyendo un fallthrough intencional) y explica tu solución.
